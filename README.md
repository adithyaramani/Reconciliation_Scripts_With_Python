Debtor Reconciliation Code for Software Migrations

One of the biggest challenges during an accounting software migration is the proper transfer of records from one system to the other. A lot of companies migrate to new software when the capabilities of their existing software has hit a bottleneck and when they require more features
A common use case in the Indian Accounting industry is the migration of data from Tally to Zoho. The main reason is to move from On-Prem to a cloud software.
We will also see cases of moving from Oracle to Tally or Tally to SAP or even Tally Effortless.

During such migrations, its important to see if the entire set of data has moved from one system to the other. The Debtor balance reconciliation is especially important as this is core module. 
We need to compare if all the records from One system have flown to the other system with the right balances
Where ever there are issues, the accounting or migration team will look into the particular accounts or debtor balances with differences and do a ledger wise drill down to see what entries or values have been left out

Post Migration reconciliation is an important step when we have migrated records from one software to another.

This Debtor reconciliation is just the first part, we will release many such python codes that can help you with your reconciliation for your migration.
